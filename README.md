# HypeSquad Badge — Chrome Extension


## What it does

Get any discord hypesquad house badge like Bravery, Brilliance, or Balance in 2026 without doing any quest . get in one click
---

## Setup

### 1. Get the files

Make sure you have this folder with the following files inside:

```
HypeSquad Badge/
├── manifest.json
├── popup.html
├── popup.css
├── popup.js
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

> **Icons** — You need to add your own icon images in the `icons/` folder (16×16, 48×48, 128×128 px PNG files named exactly as above). You can use any image you like, or just duplicate one image at different sizes.

---

### 2. Load into Chrome

1. Open Chrome and go to `chrome://extensions/`
2. Turn on **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `HypeSquad Badge` folder
5. The extension will appear in your toolbar

---

### 3. Use it

1. Go to **[discord.com](https://discord.com)** and log into your account
2. Click the extension icon in your Chrome toolbar
3. Pick a house — **Bravery**, **Brilliance**, or **Balance**
4. Or click **Remove Badge** to clear it
5. Check your Discord profile — the badge should update within a few seconds

---

## Notes

- You **must** have Discord open in the active tab when you click a button
- This runs inside Discord's own page using their internal API, so it only works on the web version (`discord.com`)
- The Discord desktop app and mobile app are not supported
- If it stops working after a Discord update, reload the Discord tab and try again
